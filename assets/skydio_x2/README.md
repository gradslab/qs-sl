# Skydio X2 mesh

The mesh `assets/X2_lowpoly.obj`, its material and its texture come from the Skydio X2 description of the
[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie), where the assets were provided by
[Skydio](https://www.skydio.com/skydio-x2) under the Apache-2.0 License reproduced in [LICENSE](LICENSE). Only the
visual files are kept here; the simulation uses the mass and inertia of the paper, not those of the X2.
